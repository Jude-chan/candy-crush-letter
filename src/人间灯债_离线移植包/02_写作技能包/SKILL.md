# Webnovel Writer（网文写手）

## Overview

本技能让 WorkBuddy 具备职业网文写手的工作流：从选题、立大纲、定人设，到逐章写作、节奏控制、签约投稿。核心方法论基于免费阅读平台（以番茄小说网为代表）的算法推荐逻辑：快节奏、强爽点、高反转、情绪稳定输出。

## 使用时机

触发场景包括：
- 「帮我写一本能签约的小说 / 生成大纲 / 设计金手指」
- 「写第 N 章 / 续写正文 / 润色这一段」
- 「番茄现在什么题材火 / 怎么签约 / 我的开头为什么留不住人」
- 「设计爽点 / 卡点 / 高潮位 / 番外」

执行流程：先读 `references/market-fanqie.md` 了解当前市场与签约标准（选题阶段必读），再按下方工作流执行。写作方法论见 `references/craft.md`（写正文前必读）。

## 工作流：从零到签约稿

### 第一步：选题定位（先选赛道，再想故事）

1. 依据 `references/market-fanqie.md` 中的赛道分级，确定「男频/女频 + 品类 + 核心梗」。
2. 用公式落地选题：**老赛道 + 新元素微创新**。例：系统流 + 冷门职业、民俗玄学 + 都市日常。拒绝纯照搬。
3. 一句话概括验证：主角是谁 + 得到什么金手指 + 干什么 + 爽点是什么。说不清就重想。
4. **选题查重（必做，不可跳过）**：定稿前用 WebSearch 至少查三轮竞品：
   - 按职业/题材外壳查（如「番茄小说 白事 殡葬 小说」），确认该外壳是否已有大体量标杆（50 万字以上或有百万在读者慎入）；
   - 按金手指核心机制查（如「小说 完成 遗愿 获得能力 传承」），确认机制是否已是成熟套路家族；
   - 按具体单元/桥段查（如捞尸、阴婚），避开顶流已占用的名场面。
   判定规则：三件套（职业外壳、金手指机制、核心桥段）撞其二即需重构；择优方向是「保留赛道，反转旧梗」，把「A 对 B 做 X」反转为未有人写过的视角（案例：「替死者圆愿」已泛滥，「替将死的活人赶在死前圆愿」为空白）。
5. **命名查重（必做，分三层，人物名同样要查）**：确定名号前用 WebSearch 加引号精确检索（如「"执念簿" 小说」），被用作书名或核心道具的名称一律弃用；候选名按「世界观绑定度、直白度、独特性」三维度评估，最终由用户选定。
   - **第一层 金手指/核心道具**：连带查相关术语（「执念」「守灯人」「长明灯」这类大众词在玄幻异能圈是高频占用区）；优选为整个能力体系造一套自洽的原创术语（案例：长明册+灯债+捻子+灯油+剪芯+死账+收账人，比单个金手指名更有品牌性）。
   - **第二层 人物名（易被忽略，必须查）**：主角/女主/师父/反派名要逐个查，重点看**同赛道是否已有同名主角**。案例：主角名「程野」撞起点民俗灵异《槐界》（该书主角同样返乡、血脉传承、守护者设定）；师父名「陈九斤」撞《憋宝实录之天下诡藏》《寻龙脉诡录》两部民俗悬疑主角；反派名「宋无咎」撞《天册没我名》主角且设定三连撞（能看见别人身上的账、从丧事讨起、册上没自己名字）。判定看三条：同赛道重合度、作品知名度、撞项数量。中文两字名几乎不可能全网唯一，不必追求零撞名，但**同赛道（都市灵异/民俗悬疑/殡葬医疗）撞车必换**。
   - **第三层 机构/组织/团体名**：现实题材尤其易撞（案例：「往生堂」被《人是大专生火葬一条龙》《青囊尸衣诡事录》《往生堂白事录》等四本占用，且两本同为殡葬题材）。
   - 替补名同样要查重后再推荐（案例：程烬/程迟/程拾/程归/陈守拙/姜晚/姜禾/韩越/安魂堂/归安堂/慈安堂/永宁堂均已确认占用，最终程照/陈有余/姜素/马顺利/宋无赦/安归堂胜出）。
   - 可选加查：核心悬念的书名化表述是否撞车（案例：「册上没有自己的名字」撞《天册没我名》，须改写为「名字被人划掉」）。
6. 拟 3-5 个标签，按「大品类 + 赛道 + 爽点」三层递进，不蹭无关热标签。

### 第二步：大纲搭建

产出物固定为一份大纲文档，必含以下模块：
1. 书名（备选 2-3 个，直白带钩子）、题材、标签、一句话简介。
2. 核心卖点（3 条以内）：金手指、人设反差、情绪主打。
3. 金手指设定：能力、限制、成长线、克制手段（无限制的金手指会杀死张力）。
4. 主角与主要配角人设卡（含缺陷与动机，拒绝工具人）。
5. 主线分卷大纲：每卷核心冲突、关键转折、卷末高潮。
6. 前三章细纲：签约生死线，逐章列冲突点与章末钩子。
7. 爽点位表：每 3 章一个小爽点，每 10 章一个大高潮（详见 craft.md）。

### 第三步：逐章写作

0. **写前强制回读（不读不动笔，硬性流程，防乱写剧情/防幻觉/防吃设定/文风统一）**：写任何新章节前按序回读五样——①全书大纲（主线+本卷+爽点位表）；②本单元细纲；③**前 2 章正文全文**（最有效的文风校准，同时防章末意象撞车；本章前 200 字必须接住上一章章末钩子）；④设定速查（规矩/术语/称谓/时间线/悬念登记）；⑤项目记忆文件 CHARACTERS.md（人物现状与知情账）与 PLOT_POINTS.md（伏笔台账）。回读产出「动笔笔记」：本章接哪个钩子、兑现哪些埋点、登记哪些新悬念，写完对照勾销。方法论见 craft.md 五点十五。
1. 每章 **2000-3000 字**（番茄最优区间）。上限分级：常规章不超 3000；情感高潮章／单元开篇章／单元收束章可用特批档至 3500（须在进度表注明理由）；**4000 为绝对红线**。下限不硬性（内容饱满紧凑时不强行凑字），但不低于 1800。开篇 300 字内进冲突，章内不复述上章内容。**段落地模同步卡数字**（防「短视频分镜化」）：均段 ≥25 字、≤12 字短段占比 ≤25%、连续单句成段 ≤3 行，与字数校验同轮跑脚本（skill 自带 `scripts/check_chapter.py`：`python scripts/check_chapter.py --dir 02_正文`，特批档加 `--special`；一次输出字数、段数、均段、短段占比、连续单句、破折号／直角引号／引号配对、否定式反应候选、称谓雷区、喻体复用、对话占比、生僻字扫描）；**完稿章节若超标，按 craft.md 五节「完稿章节回修四步法」处理**（量化扫描 → 定位到段判「碎段 / 重锤」→ 三类合并 → 复扫验收），纪律是**只合不删、不动台词、节奏重锤优先于数字**。依据与数据、自检案例均见 craft.md 五节。
2. 每章结构：承接上章钩子 → 推进冲突 → 爽点或反转当场兑现 → 章末留钩（悬念/反转/危机/期待）。**章末钩子三忌**：忌把本章前文用过的同一节奏块再排一遍（复述改成变奏，第二次必须多走一步）、忌与上一章章末用同一意象收尾（章末意象要成阶梯不许成回声）、忌提前报出下一章的行动计划（把悬念换成任务）；**末句落在变化上，给动作不给结论、给进行时不给完成时**（见 craft.md 五点十二）。**单元收束章按 craft.md 五点十四范式写**（账本清点＋小场景快切＋笑泪间隔＋变奏兑现，写完加跑七问自检），范式是检查清单不是生成模板，命中防模板化警报任一条即重构。
3. 遵守 `references/craft.md` 的文风规范：大白话基调，打脸反转写直白，允许贴吧式粗粝但不难看；民俗题材另须执行「港式恐怖单元风格」（仅穿插约 25% 单元，道具自洽、仪式写实、恐怖与市井穿插、人情内核）与「年代感与真实感民俗写法」（物件定年代、行话立规矩、场景错开同类书招牌场景）。**对话戏单独过 craft.md 五点十三十条纪律**：审讯式短交锋连排 ≥3 句即改（加来回、半截话、环境打断）；「A 要 B 看 C 做 D」句先核主宾方向；「还／递／塞／交」类双向动作句主语落名字、写清谁给谁，「动词＋来／去」趋向补语归点对账（见清单第 24 条）；**道具不跨单元复用**（A 单元泪点道具不得给 B 单元人物当随手物件）；配角对主角的称谓动笔前先 grep 前文（防止直呼名字的吃书）；超感知场景先核设定速查的金手指感知边界；一段内换说话人必须有归属引导；**引号紧贴最近动作的主人——搀扶场景话归被扶者、耳语用「动作＋转述标记＋称呼」三重锚定（见五点十三第 8 条）**；**开口前先核听者已知什么，向知情人转述旧闻＝作者借嘴念稿（见五点十三第 9 条）**；**人物打比方过三道关：物权（从他自己的世界取物，先查物件归谁）、因果（比喻内在逻辑要推得通）、重复（同义至多两拍，见五点十三第 10 条）**；**身体传导顺着身体长（烫从胎记那只手出）**；**引前文数据（金额/次数/已知情）必先 grep 原文**。
4. **每章写完必跑 craft.md 的「AI 味自检」十条与「成稿硬伤检查清单」二十五条**（名词先后、信息来源、生僻字、场景适用性、时间线、前后一致、硬指标脚本校验、配角计数一致、核心术语与口语隔离、台词夸张力度匹配、称谓歧义与脏话谐音、行业标签与职责相符、动词的物理前提、金手指物件实体化先立规矩、机制讲解先原理后道具＋代价归属第一人称锚定、规则反例测试＋伏笔登记回收点、序数词回指必须有名有姓的前项、金手指兑现画面必须与已立规则对账、人物方位动线自检、金手指关键部件先看见再动用、叙述判定与反应强度对账、旧人物简称挂锚＋生死时态对账、道具字迹先示原文、双向动作句主语落名字＋趋向补语归点对账、对话人称回声对账），命中即改，不过关不交付。
5. **每章过「五道闸门」**（情绪／钩子／人味／一致／合规，见 craft.md 五点九），任一道不过不得进入下一章；**每 3~5 章列一次「爆点地图」**（爆点位／位置%／类型／主角收益），命中「连续两章同功能爽点」「三章内无主角自挣收益」「主线断档」三条判定即需调整，签约投递前必须全稿过一遍。另须独立检查两条：**金手指成长线是否在前 2 万字内完成一次可见闭环**（付出 → 获得 → 收益可视化，缺收益读者和编辑都看不出成长线）；**打脸是否扎堆或夹在情绪最高点与章末钩子之间**（打脸场的排布原则见 craft.md 五点九，位置错了强度再高也白搭）。
6. **写打脸章前先做两件事**：① 翻反派全部前文出场，列「回旋镖账本」——他羞辱过的每一句都配一条回收，**未回收的羞辱＝未兑现的爽点**；② 按「四级递进」自查（揭穿 → 夺回 → 定性 → 收益），**只做到二级不算够签约线**，三级须剥夺对方的社会身份且失败可见，四级须保证**净收益为正、代价在收益之后结算**（详见 craft.md 五点九）。另：围观群众的反应必须从他们自己的处境里长出来，**拿不准就不写**，禁止为营造憋屈硬派群众反应；**禁止否定式反应**（「没人笑」「没人说话」「没人接话」「全场鸦雀无声」——它什么都不描述，只把作者推到台前，是「被删场景的鬼影」）；**不许补旁白解释反应**；一章里纯气氛型围观反应 ≤1 处，匿名主语（有人／众人）只留给人群真转向的时刻。**同一条纪律适用于单个角色**：别用「他没接话／没答／没吭声」报告沉默（这类句子是全书最高频的模板，本书原稿主角占 11 处），要么删（让对方的下一句追问演出来），要么换成动作（他没有话说，于是做一件事）；同一措辞同角色全书 ≤1 次，主角沉默反应总数 ≤3 处（见 craft.md 五点十一）。
7. 用户有特殊文风要求（如禁用某标点、机构命名统一）时，写入长期记忆并在所有章节中强制执行。
8. **每章完稿后更新项目记忆文件三件套（固定动作，防后期吃设定）**：①设定速查——新规矩、新悬念（登记回收点）、时间线锚点；②CHARACTERS.md——人物「当前状态」行与增量（知情账/计数账/位置账/持有物/称谓）；③PLOT_POINTS.md——新埋点加行、兑现埋点改状态（待回收→进行中→已回收）。历史记录不删；三份文件口径冲突时以正文为准，当场改正另两份。

### 第四步：签约投递

1. 首签硬线：≥2 万字、100% 原创、无敏感内容。
2. 检查清单：开篇 300 字有冲突？第一章结尾前金手指落地？前三章各有爽点？主线一句话说得清？
3. 投稿时填对题材分类与标签，简介用短句+冲突，不写世界观论文。

## 红线与避坑

- 慢热铺垫、无金手指、无情感线是新人被拒前三名。
- 不写大段环境/心理描写，2 万字内全是有效剧情。
- 涉及现实机构、真实人物、敏感话题一律架空或回避。
- 正文遵守用户已有偏好：少用破折号等标点规范以用户记忆为准。
