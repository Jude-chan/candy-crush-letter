# 番茄小说网市场与签约指南（2026 年 9 月更新）

数据来源分两级：
- **官方资料（可信，优先采用）**：番茄作家帮助中心签约指南（notice.fanqienovel.com/docs/9476/dianziqian）、番茄作家专区编辑说（fanqienovel.com/writer/zone）、「新引力」官方激励计划文章。使用前如距更新日超过 3 个月，用 WebSearch 刷新（限定 site:fanqienovel.com 或 notice.fanqienovel.com）。
- **行业拆解（参考，仅供参考）**：第三方自媒体拆解数据（赛道占比、过稿率等数字无官方背书，仅作方向参考，不写进给用户的正式建议中作为事实）。

## 一、平台逻辑

- 免费阅读 + 算法推流，主打「快节奏、强爽点、高反转」，签约门槛全平台最低，新人友好。
- 2025 年末推出「新引力计划」：扶持「拉新向」题材，即能通过短视频素材（推书、配音、漫剪）把非读者转化为读者的作品。
- 2026 年核心方向：短篇为王、短剧适配、脑洞破圈、情绪拉满。平台优先扶持「节奏快、冲突强、易改编、情绪稳」的作品。
- 编辑初审 3 秒扫题材和标签，题材选偏 + 标签乱填是新人卡签的头号原因。

## 二、签约硬指标（官方签约指南，notice.fanqienovel.com/docs/9476/dianziqian）

1. 作品满 2 万字后获得签约申请资格（电脑端作家后台 fanqienovel.com/main/writer/book-manage 申请；作家助手 App 只能发起，填写与签署须在电脑端完成）。
2. **每部作品只有 1 次签约评估机会**：若首次评估未通过，该作品后续无法再与平台签约。故 2 万字首签稿务必打磨到位再提交。
3. 原创度要求：无抄袭、枪稿续写、旧稿挪用、恶意重复章节；AI 水文/低质拼接会被打回。
4. 内容安全红线（官方安全审核）：「内容不适合收录」「低俗色情」「学生负面导向」「格式未分段」等会被审核打回。
5. 编辑评估三维度（官方明示）：
   - 题材是否适合签约；
   - 作品的节奏、人物设定、开篇、代入感、主线是否满足要求；
   - 是否存在不安全、低俗、言语不通、故事性不强、侵权等底线问题。
6. 签约后收益：广告分成 + 签约分成 + 全勤奖等额外福利（fanqienovel.com/welfare）；每月第二个周四发放稿费，满 100 元可提现。

参考补充（行业拆解，非官方）：2 万字签约过稿率全平台约 55-60%；男频都市/脑洞/异能最高，慢热/纯现实/无系统最低。

编辑实操关注点（源自编辑说与行业共识）：开篇 300 字出冲突/钩子，前三章留存决定生死；主线清晰、金手指明确（男频）/情感线清晰（女频）；每章 1500-2500 字，3-5 章一个小爽点；段落 ≤5 行，文本干净。

> **2026-09 复核补注（本章字数，官方 + 行业两级口径）**：官方帮助中心明确「章节字数至少 1000 字（否则无法发布，点不了下一步），至多 50000 字，作者可根据故事节奏自行安排，一般一章 2000/3000/4000/5000/6000 字居多」，即**官方没有"不宜过长"的硬性上限**；行业实操则一致指向 2000-3000 为最优区间（免费阅读=碎片时间，短章=多一次章末钩子=多一次追更冲动，单章完读率是算法核心指标），**超 3000 开始偏长、超 4000 明显掉完读率**。本书据此采用：常规章 2000-3000（严格不超 3000）；情感高潮章／单元开篇章／单元收束章特批至 3500；4000 为绝对红线；下限不低于 1800。

## 三、官方拉新扶持：「新引力」计划（官方，2025-12 发布，2026 持续有效）

- 官方定义「拉新」：作品素材在短视频平台传播，把非读者转化为平台读者。题材符合拉新方向即可自动享受官方投放，作者无需任何操作。
- 激励对象：中长篇独家原创首发非同人签约作品；按拉新量发放激励，拉新越多激励越高，单部作品单月最高可获 50 万元+ 激励金（与广告分成叠加），共享千万奖金池。
- 附加权益：优质作品优先短剧、漫剧、真人有声等版权开发。
- 官方开篇要求（原文要点）：开篇集中释放核心爽点与剧情钩子，既要适配短视频素材高光剪辑，又能快速抓住注意力；第一章留不住读者，拉新素材转化率就低。

**官方八大激励分类与高热方向**（含官方举例）：
1. 豪门总裁（女频）：破镜重圆极致拉扯、1V1 从一而终、掉马期待、追妻火葬场、带崽重逢。
2. 宫斗宅斗（女频）：追妻主线、重生团宠复仇、读心术金手指、双向救赎。
3. 职场婚恋（女频）：事业+感情双线并行。
4. 青春甜宠（女频）：重生改嫁、竹马暗恋守护者。
5. 都市日常（男频）：草根逆袭、小人物共鸣、升级节奏。
6. 玄幻脑洞（男频）：系统召唤+历史名将无敌爽（例《废物皇子登基，开局召唤不良帅》）、反内卷摆烂流单元剧。
7. 都市脑洞（男频）：基建系统、极致效率碾压逆袭。
8. 历史脑洞（男频）：系统解构经典（例《跟宋江决裂后，我二龙山强的可怕》）。

平台同时声明：非活动分类但具备「脑洞设定、反差人设、强情绪、强暧昧」特质的内容同样给推书资源与拉新激励。

## 四、男频赛道分级（官方编辑说为主，行业拆解为辅）

官方编辑说拉新高热分类：都市种田、都市日常、都市脑洞、传统玄幻、都市官场、战神赘婿、历史架空、历史脑洞。
官方编辑说高热核心梗：穿越、小人物逆袭、重生打脸、高光人设、系统、赘婿、扮猪吃虎、身份反差、强大背景梗、权谋、赌石鉴宝。
官方编辑说四大打法（附官方例书）：
1. 玄幻&历史：开局天赋强大却被愚蠢统治者/家主抛弃，主角强势降临（例《躺平修仙：道侣修炼我变强》《穿越大乾，从病秧子开始蜕变》）。
2. 脑洞系统爽文：多主角+废柴逆袭+开篇强噱头（肩挑八房类）+扮猪吃虎（例《七兄战死，我挑起家族复兴重担》）。
3. 传统都市：人设成熟有勇有谋+剧情层层递进+真实感强（例《29岁白衬衫，大佬说我前途无量》）。
4. 年代：重生弥补遗憾+发家致富+人设反差（例《重生八零：从小山村走出个大富翁》）。

行业拆解补充（非官方）：

| 赛道 | 级别 | 核心逻辑 |
|---|---|---|
| 都市脑洞/异能/高武 | S 级，完读率 76%，签约占比 35% | 现代背景 + 反套路金手指，短剧改编率超 60% |
| 规则怪谈/无限流 | 顶流黑马，增长最快 | 死亡游戏 + 逻辑破局 + 人性博弈 + 单元剧副本 |
| 赘婿逆袭/战神归来 | A 级，霸榜基本盘 | 身份反差 + 强爽点，30-45 岁蓝领读者 |
| 都市修真/种田 | A 级，完读率 TOP3 | 都市 + 修真/种田融合，接地气爽点密 |
| 传统玄幻逆袭 | 基本盘大，卷度高 | 系统 + 废柴流 + 打脸 + 无敌 |
| 西幻领主 | 蓝海，竞争小 | 领地养成 + 家族成长，可加东方元素差异化 |

男频签约套路公式（行业拆解，90% 签约书适用）：
- 都市异能：普通人 + 觉醒 S 级异能 + 打脸权贵 + 国家机构找上门。
- 系统流：废柴开局 + 神级系统 + 签到升级 + 扮猪吃虎。
- 悬疑无限流：死亡游戏 + 逻辑破局 + 人性博弈 + 单元剧副本。

## 七、流量密码与避坑（编辑说官方观点 + 行业共识）

流量密码（前两条为编辑说官方观点）：
1. 官方：第一章是否留住读者至关重要。高情绪/高仇恨值/强甜宠/极致反差/明显冲突/强矛盾，取一个或多个用在第一章。
2. 官方：开篇集中释放核心爽点与剧情钩子，适配短视频素材高光剪辑；故事切忌平淡流水。
3. 每 10 章留 1 个大高潮，反转密集，台词简洁有画面感（方便短剧改编）。
4. 老套路 + 新设定微创新（系统流 + 冷门职业、重生 + 民俗玄学）。
5. 题材符合拉新方向即可自动获得官方投放（素材拉新、达人拉新、自然拉新三渠道），优先选择「新引力计划」八大分类。

最容易被拒的五点：
1. 慢热铺垫：前 3 章没冲突、没金手指、没钩子。
2. 无明确金手指（男频）/无情感线（女频）。
3. 人设平庸：主角无记忆点。
4. 情绪平淡：爽甜虐燃四种情绪切换不密集。
5. 水文：大段环境/心理描写，无效剧情。
